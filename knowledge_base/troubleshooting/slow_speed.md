# Bandwidth and Speed Drop Troubleshooting

## Overview
Guidelines to diagnose throughput drops below subscribed bandwidth limits.

## Diagnostic Steps
1. **Direct Wired Test**: Disconnect WiFi and connect test laptop directly to modem ethernet port using a Cat6 cable.
2. **Close Background Applications**: Disable cloud backups, peer-to-peer downloads, and VPN clients during speed testing.
3. **Execute Speed Test**: Perform test at official carrier speed test portal.
